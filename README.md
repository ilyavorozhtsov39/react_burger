# Скрипты:

`npm run start` - запукск development-режима;

`npm run build` - сборка прокекта;

`npm run deploy` - деплой сборки в Github Pages;

`npm run test` - запуск тестов Jest;

`npm run cypress` - запуск текстов Cypress;
