# Скрипты:

`npm run start` - запуск development-режима;

`npm run build` - сборка проекта;

`npm run deploy` - деплой сборки в Github Pages;

`npm run test` - запуск тестов Jest;

`npm run cypress` - запуск тестов Cypress;
